If you need to convert between the linked-read technologies' distinct FASTQ formats and their
barcoding systems, use `convert`. It auto-detects the input format as one of 10X, haplotagging, TELLseq, or stLFR,
and converts it to the format provided as the `TARGET` positional argument. If the
input data is in 10X format, where the barcode is usually the first 16 bases in the R1 sequence,
you will need to provide a `--bc-map` file that lets Djinn know what barcodes to look for.
In all cases, a file will be created with the barcode conversion map.

## Usage
Accepts one unpaired FASTQ file or two paired FASTQ files (R1 and R2, can be gzipped), with barcodes specified in BX:Z SAM tag. Writes prefix.R1.fq.gz (and prefix.R2.fq.gz if paired). The first positional argument outFormat specifies the target data format (standard, haplotagging, tellseq, stlfr, 10x). Specifying 10X output will draw barcodes from the official 10X Genomics barcode whitelist.

```bash
convert [options] TARGET PREFIX file.R1.fq.gz [file.R2.fq.gz]
```

Example:
```bash
convert 10x gcurratum_as10X gcurratum.R1.fq.gz gcurratum.R2.fq.gz
```




## Options
| argument         | description                                                                                |
| :--------------- | :----------------------------------------------------------------------------------------- |
| `PREFIX`         |  output filename prefix   <Badge text="required" variant="tip" />    |
| `TARGET`         | output barcode and FASTQ style: `10x`, `haplotagging`, `tellseq`, `stlfr`, `standard` |
| `file.R*.fq.gz`  | FASTQ file or file pair <Badge text="required" variant="tip" />                                       |
| `-b` `--bc-map`  | Valid barcode list <Badge text="required: for 10X Genomics input" variant="tip" />   |


<details>
    <summary> example `--bc-map` file </summary>
```
ATGGAAGCCGTAGTTA
ACGGAAGCCGTAGTTC
ATGGAAGAAATAGTTA
ATGTTTGCCGTAGTTT
```
</details>

## Conversion targets

| `TARGET` | barcode format                                   | example      |
| :---------------------------- | :----------------------------------------------- | :------------------------------- |
| `10x`                         | the first N base pairs of R1 |                                  |
| `haplotagging`                | a `BX:Z:ACBD` SAM tag in the sequence header     | `@SEQID BX:Z:A01C93B56D11`       |
| `standard`                    | `BX:Z` and `VX:i` SAM tags in the sequence header     | `@SEQID BX:Z:TGGTAGA VX:i:1` |
| `stlfr`                       | `#1_2_3` format appended to the sequence ID      | `@SEQID#1_2_3`                   |
| `tellseq`                     | `:ATCG` format appended to the sequence ID       | `@SEQID:GGCAAATATCGAGAAGTC`      |
