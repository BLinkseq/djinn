While downsampling (subsampling) FASTQ files is relatively simple with tools such as `awk`, `seqtk`, `seqkit`, etc.,
`sample` allows you to downsample FASTQ(s) **by barcodes**. That means you can
keep all the reads associated with `-d` number of barcodes or fraction of barcodes.
- if `-d` > 1, djinn will keep `d` barcodes
- if `-d` < 1, djinn will downsample to a fraction of all barcodes
  - e.g., `-d 0.5` will downsample to 50% of all barcodes

## Usage
```bash
djinn fastq sample -d <value> [-i] PREFIX file.R1.fq.gz [file.R2.fq.gz]
```

Example: downsample fastq pair, including invalid barcodes
```bash
djinn fastq sample -d 1000 -i sample1.sub1000 sample1.F.fq.gz sample1.R.fq.gz
```

Example: reproducibly downsample barcodes by 50%
```bash
djinn fastq sample -d 0.5 -s 111 sample1.half sample1.F.fq.gz sample1.R.fq.gz
```

## Options
| argument            | description                                                                            |
| :------------------ | :------------------------------------------------------------------------------------- |
| `PREFIX`            |  output filename prefix   <Badge text="required" variant="tip" />    |
| `file.R*.fq.gz`     | FASTQ file or file pair <Badge text="required" variant="tip" />                               |
| `-d` `--downsample` | number/fraction of barcodes to downsample to   <Badge text="required" variant="tip" /> |
| `-i` `--invalid`    | include invalid barcodes in downsampling                                               |
| `-s` `--seed`       | random seed for sampling <Badge text="optional" variant="note" />                       |
