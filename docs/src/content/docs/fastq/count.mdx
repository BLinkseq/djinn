You might want a table of the counts (frequency) of all the unique barcodes in your data and that's what `count`
is for. Records with missing barcodes are ignored. Writes to `stdout`.

You can use one file of a pair (e.g. R1 or R2), but including both files will prioritize counting the first file
and only count occurences of _new_ barcodes in the second file that aren't present in the first file. This is done
to avoid double-counting barcodes.


## Usage
```bash
djinn fastq count file.R1.fq.gz [file.R2.fq.gz]
```

Example: count only valid barcodes
```bash
djinn fastq count sample1.F.fq.gz sample1.R.fq.gz > sample1.bxcount
```

## Options
| argument          | description                                                                   |
|:------------------|:------------------------------------------------------------------------------|
| `file.R*.fq.gz`   | FASTQ file or file pair <Badge text="required" variant="tip" />                          |
| `-i` `--invalid`  | Include invalid barcodes                                                      |
